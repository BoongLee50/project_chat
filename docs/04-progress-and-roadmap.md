## 3. 확실히 지정해야 하는 것 (미결정)

이후 작업 방향을 좌우하므로 재개 전에 결정 권장. **1·2·3 확정됨.** 남은 것(4~8)은 대부분 외부 계정/배포 시점 이슈.

> **작업 분담(2026-07)**: 서버 개발자 = 초기 뼈대 + 추후 클라우드(AWS 등) 배포. **그 사이 실제 개발(서버 도메인 구현 + 클라 연동 + 로컬 통합)은 이 저장소에서 직접 진행.** 진행 방식 = 기능별 수직 슬라이스(로그인/온보딩부터 서버+클라 end-to-end).

> **BM(수익모델) 기획 — 추후 별도 전달 예정**: 코어 개발과 **별개 트랙**으로 진행(기다리지 않음). 수익 "메커니즘"(루나 차감·프리미엄 분기 배관)은 기획서/스키마에 이미 있으므로 **값을 하드코딩하지 않고 설정 기반으로 선행 구현**. BM이 채우는 것(루나 가격·프리미엄 상품 구성·인앱결제·광고)은 **격리 모듈 + 외부 계정 필요**라 기획 도착 후 붙여도 재작업 최소. 완전히 새로운 수익 기능(선물/가챠 등)이 오면 그때 화면/도메인 "추가".
