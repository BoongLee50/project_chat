**서버 (Spring Boot)** — 서버 개발자 초기 구현 + 로컬 빌드 환경 구축

- **로컬 풀스택 구동 완료(2026-08)**: JDK 17 + Gradle 8.10.2 + **로컬 MariaDB 11.4.5** → Flyway V1 스키마 적용, **Spring Boot 8080 구동 성공**(`/system/gate` 200, 인증 401). 세팅 절차 = [06 개발환경](06-dev-environment-setup.md).
  - MariaDB 11.4 호환 이슈 1건 수정: `chat_rooms.active_pair_key` 생성컬럼→앱세팅(커밋 `40d9130`). REST 날짜=ISO-8601 확인.
- 구현 완료(서버): auth/profile · post · garden · chat(+WebSocket) · friend · luna · **store(BM)** · scheduler. Flyway **V6**까지 적용.

**앱 UI — 화면 11개** (정적, 다크 테마 고정, Android 에뮬레이터 검증 완료)
- 로그인 → 온보딩 3단계(닉네임 · 출생년도 · 성별/국가)
- 메인 셸(하단 5탭 IndexedStack):
  - 포스트(오늘의 포스트/홈) · 달빛가든(피드) · 대화방 → 채팅창 · 친구 · 프로필
- 디자인 시스템(`app_colors`/`app_dimens`/`app_theme`), feature-first 구조, 공용 하단 내비(`MainBottomNav`)

> 현재는 "정적 UI" = 코드로 만든 화면 + 더미 데이터/사진. 상호작용(입력·검증·탭 전환·화면 이동)은 동작하나, 서버 데이터·실기능은 미연결.

### 친구 기획 수정 시 흔들릴 것 (2026-08-08 미팅 대비)

이미 구현이 끝난 영역이라, 어디가 바뀌면 무엇을 고쳐야 하는지 미리 정리해 둔다.
**미팅에서 이 목록을 훑으면 수정 범위를 그 자리에서 가늠할 수 있다.**

| 지금 구현된 것 | 바뀌면 손대야 하는 곳 |
|---|---|
| **최대 친구 수 20명**(프라임 30) — 기획서에 20 vs 30이 엇갈려 잠정값 | `app.friend.max-count` **설정만 변경**(코드 수정 불필요). 문구는 서버가 숫자를 `field`로 실어 보내고 ARB가 조립하므로 자동 반영 |
| **친구 요청 진입점 = 채팅창 메뉴만** | 진입점이 늘면(가든 프로필·친구 목록 등) 클라 화면 추가. 서버 API는 그대로 |
| **수락 시 상시 대화방 생성 / 기존 MATCH 방 승격** | 관계 모델이 바뀌면 `friendships`(V5)와 `chat_rooms.type` 양쪽. **마이그레이션 필요할 수 있음** |
| **친구 방은 24시간 개방**(게이트 예외) | 친구도 운영시간을 타게 되면 `requireGateOpen()` 적용 범위 + 화면 배너 분기 |
| **메시지 보관 친구 1년**(매칭 30일) | 보관 정책 재확정 → 스케줄러 2차 |
| **친구 삭제 = 즉시 관계 해제 + 상시 대화방 종료** | 유예·차단 구분 등이 생기면 서버 부수효과 재설계 |
| **오늘의 포스트 조회**(`GET /friends/:id/today-post`) | 공개 범위가 바뀌면 API 권한 판정 |
| **친구 화면 문구**(ARB `friends*` 키) | 문구 변경은 ARB만. **일본어도 함께 고쳐야 한다**(현재 초벌) |

⚠️ **친구 쪽 신규 작업은 8/8 이후로 미룰 것.** 지금 손대면 수정본과 충돌해 두 번 일하게 된다.
