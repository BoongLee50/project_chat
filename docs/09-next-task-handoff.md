## 2. 다음 작업 — Plan_3 ③단계: 달빛가든

**두 덩어리다.** ⓐ 열람 제한(BM 장치)과 ⓑ 노출 알고리즘 재구현. 서로 독립적이라 ⓐ부터 해도 된다.

### 2-1. ⓐ 열람 제한 🔴 ([12 §2-3](12-plan3-diff.md))

- 무료 사용자는 상대의 **메인 사진 1장만** 본다.
- 전부 보려면 **오늘 내 새 사진 1장을 등록하고 [공유하기]까지** 해야 한다. **18시 초기화.**
- 미등록 상태에서 **2번째 사진을 넘기면** 하단에 [사진 등록 안내창].
- **프라임·앨범패스는 무제한.**

> 🚨 **화면에서 자르지 말 것.** API를 직접 부르면 그만이다(함정 #18의 재발 방지).
> **서버가 `photoUrls`를 1장으로 잘라 내려보내고**, 클라는 "더 있는데 잠겨 있다"는 신호
> (예: `photoLocked: true` + `totalPhotos`)만 받아 안내창을 띄운다.
> 자물쇠 뒤의 URL이 응답에 들어 있으면 제한이 아니다.

판정식은 **"오늘 영업일에 published된 내 포스트에 사진이 1장 이상"** 이다 —
`posts.session_date = 오늘 AND published_at IS NOT NULL AND 사진 ≥ 1`.

### 2-2. ⓑ 노출 알고리즘 🔴 ([12 §4-2](12-plan3-diff.md))

기획서가 **숫자까지 명시**했다. 지금 스코어(`score-pick` 50 / `score-online` 10)와 다르다.

```
Post Score = Online + Recency + Engage
Online  : 접속 중 10 / 미접속 0
Recency : 1h 이내 30 / 1~3h 20 / 3~5h 10 / 5h 초과 0   (사진 갱신 시각 기준)
Engage  : {(좋아요×1)+(댓글×2)+(대화신청×4)} / 총 노출 × 100
          30%↑ 30 / 20%↑ 20 / 15~19.9% 15 / 10~14.9% 10 / 5~9.9% 5 / 그 이하 0
          * 총 노출 20회 미만이면 0
          * 전환율만 18시 초기화
```

| 같이 바뀌는 규칙 | 지금 |
|---|---|
| **노출 순서 고정** — 진입 시 1회 산정, 세션 동안 유지 | 매 요청 셔플 |
| **15분 노출 제외** | `feed_skips`는 하루 단위 |
| **부스트 별도 풀 + 6:4 랜덤 믹싱**(부스트 풀이 더 크면 비율 반대) | 없음 |
| **노출 횟수 집계** — 스킵·검색·좋아요도 1회로 산정 | `post_stats.exposures`가 이 정의와 다를 수 있다 |

> ✅ **[07 §5-2 피드 확장성 부채의 답이 이것이다.** "진입 시 1회 산정 후 순서 고정"이
> 곧 페이징이 어긋나던 원인의 해결이다. 부채 2건이 여기서 함께 닫힌다.

> ⏳ **부스트 "구매 즉시 3회 노출 우선권"만 미결**([12 §6 B3](12-plan3-diff.md)).
> **나머지를 먼저 만들고 마지막에 붙인다** — 별도 풀·6:4 믹싱은 답 없이도 확정이다.
> 부스트 본체는 확인됐다: **스코어 공식은 양쪽 동일**, 혜택의 실체는 **풀을 나누는 것**이고
> **"10배"는 광고 문구**다.

### 2-3. 완료 기준

- [ ] 무료 사용자에게 **서버가 사진을 1장만 내려보낸다**(응답에 나머지 URL이 없다)

## 4. 작업하기 전에 꼭 읽을 것

**[12 §6](12-plan3-diff.md)의 원칙 둘** — ①②단계에서 실제로 두 번 다 걸렸다.

1. **기획서에 없으면 사라진 것으로 본다.** 재활용은 "비슷해 보여서"가 아니라 **규칙이 실제로 같을 때만**.
2. 🚨 **콘텐츠 이름은 언제든 바뀐다** — **이름을 식별자로 쓰지 말 것.**
   ①단계에서 `oneLiner` 필드를 `intro`로 바꾼 것이 같은 이유다.

**②단계에서 새로 얻은 습관 하나** — **숫자를 문구에 굳히지 말 것.**
장수·횟수·한도는 설정값이라 언제든 바뀐다. 서버가 `field`에 실어 보내고 **ARB가 조립**한다.
실제로 ARB에 박혀 있던 "8장"이 ①단계 직후 곧바로 거짓말이 돼 있었다.
