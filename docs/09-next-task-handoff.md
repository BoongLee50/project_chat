## 1. 지금 무슨 상황인가

**Plan_3 ①단계가 끝났다.** 앱의 전제 두 가지가 바뀐 상태다.

- **야간 운영시간이 없다.** 24시간 열려 있고, 게이트 판정·화면·배치·ARB가 전부 사라졌다.
- **"하루"의 경계가 KST 18시**다(`app.session.rollover-hour`). 6개 테이블이 이 경계를 쓴다.
- 함께 걷어낸 것: 포스트 등록 창(1시간) · 하루 한 마디 · [보낸 신청] 탭 · 스포트라이트 부스트.
- 값 반영: 사진 유료 **9장** · 사진 교체 **3/3** · 친구 **100/100** · 대화 신청 무료 **10회/일**.

자세한 내용은 [07 §4 「2026-08-29(4)」](07-work-log.md).

> ⚠️ **낮에 개발할 때 `--app.gate.open-hour=0`은 이제 쓰지 말 것** — 없는 설정이다.
> 대신 **18시 이전이면 `session_date`가 어제**라는 점을 기억할 것([07 §2-4](07-work-log.md)).

**다국어 ③단계(일본어 검수)는 계속 보류다.** 화면이 계속 바뀐다.

## 2. 다음 작업 — Plan_3 ②단계: 포스트

**왜 이것부터인가**: **③단계(달빛가든 열람 제한)의 전제**다.
열람 제한이 *"무료는 상대의 **메인 사진** 1장만"* 인데, 지금 `post_photos`에 **메인 플래그가 없다**
(`order_idx`만 있다). 메인 사진 없이 가든을 먼저 만들면 두 번 만들게 된다.

### 2-1. 메인 사진 지정 🔴 (DB 변경)

기획서 [12 §2-4](12-plan3-diff.md):

- `[메인]` 버튼으로 **달빛가든에 노출할 대표 사진**을 고른다.
- **최초 사진은 자동 메인.**
- **메인을 지우면 다음 슬롯이 자동으로 메인**이 된다(비는 순간이 없어야 한다).
- 신규 사진은 등록 시간순 슬롯(**1번이 최신**).

| 층 | 할 일 |
|---|---|
| DB | **V11** — `post_photos`에 메인 표시 추가. `is_main BOOLEAN` 또는 `posts.main_photo_id` 중 택1 |
| 서버 | 등록/삭제 시 **자동 승계 규칙**을 서비스에서 보장. 메인 지정 API 신설 |
| 클라 | 사진 슬롯에 `[메인]` 버튼 + 메인 배지 |

> 💡 **설계 판단이 필요한 지점**: `is_main` 플래그를 쓰면 "한 포스트에 메인 하나"를 **DB가 보장하지 못한다**
> (유니크 제약이 부분 인덱스를 요구한다). `posts.main_photo_id` FK로 두면 **구조상 하나만 존재**한다.
> 승계 규칙(지우면 다음 슬롯)이 있으므로 **후자를 권한다** — 다만 사진 삭제 시 FK 정리 순서에 주의.

### 2-2. 사진 9장 · 삭제 3회 🟢 (설정 — **이미 반영됨**)

`app.post.max-photos-pass: 9` · `replace-limit-free: 3` · `replace-limit-pass: 3` 은
**①단계에서 이미 값을 바꿔 뒀다.** ②단계에서는 **화면 문구·슬롯 개수가 9장을 제대로 따라가는지**만 확인하면 된다.

- 앨범 패스 화면·상점 설명에 **"8장"이 문구로 박혀 있지 않은지** ARB를 훑을 것.
- 홈 사진 그리드가 `maxPhotos`를 서버에서 받아 그리는지(하드코딩 8이 없는지).

> ⚠️ `replace-limit-free`/`pass` **두 키는 값이 같아도 지우지 말 것.** 나중에 다시 갈릴 수 있다([12 §6 B4](12-plan3-diff.md)).

### 2-3. 완료 기준

- [ ] **V11** 적용, 메인 사진이 DB에 표현된다
- [ ] 첫 사진이 **자동 메인**이 되고, 메인을 지우면 **다음 슬롯이 자동 승계**된다
- [ ] `[메인]` 버튼·배지가 화면에 있고, 서버 응답에 메인 정보가 실린다
- [ ] 유료 사용자가 **9장**까지 올릴 수 있고, 하드코딩 "8"이 남아 있지 않다
- [ ] 사진 삭제가 **하루 3회**에서 막힌다(무료·유료 동일)
- [ ] `flutter analyze lib test` 0건 · `flutter test` 통과 · 서버 컴파일 성공
- [ ] 에뮬 2대로 **내 메인 사진이 상대 가든 카드에 나오는지** 확인
