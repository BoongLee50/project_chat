## 2. 다음 작업 — Plan_3 ⑤단계: 달빛 한마디

**매일 질문 하나에 한마디(100자) + 사진 1장(선택)으로 답하고 서로 보는 이벤트.**

### 2-1. 진입과 화면 흐름 (기획 8-1)

```
달빛가든 필터 줄 4번째 [🌙 달빛 한마디]      ← 334×94, 스포트라이트가 있던 자리
   → [타이틀] 오늘의 질문 + 참여 인원 + 남은 시간 카운트다운 + [참여하기]
   → [목록]  최신순 / 인기순 / [내 한마디]  + 작성 FAB
   → [상세]  한마디 + 사진 + 좋아요/댓글 + 댓글 스레드(④단계 그대로)
```

- **18시에 모든 정보가 초기화**되고 새 질문이 나온다. 화면 문구도 *"매일 저녁 6시에 새로운 미션이 열려요"*.
- **인기순 = 좋아요 + 댓글 수치의 총합.** 기본은 최신순.
- 내 글이 없을 때 `[내 한마디]` → *"아직 작성한 내 한마디가 없어요. 오늘의 질문에 답해 보세요."*
- 작성은 **100자**, 메인 이미지 **1장(선택)**.
  ⚠️ 작성 화면 **이미지에는 썸네일이 3장** 보이지만 **본문은 "최대 1장"** 이다 — **본문이 정본**이다.

### 2-2. 만들 것 🔴

| 층 | 내용 |
|---|---|
| DB(**V14**) | 질문(일자별) · 답변(사용자×일자) · 좋아요. 댓글은 **④단계 구조 재사용** |
| 서버 | 오늘의 질문 조회 · 참여자 수 · 목록(최신/인기) · 작성 · 좋아요 · 내 글 |
| 클라 | 타이틀 · 목록 · 상세 · 작성 화면 4개 + **가든 필터 줄 4번째 버튼** |

> 🚨 **콘텐츠 이름을 식별자로 쓰지 말 것**([12 §6 E](12-plan3-diff.md)).
> "달빛우편"이 "달빛 한마디"가 된 전례가 있다. 테이블·컬럼·enum·API 경로·ARB 키는
> `daily_question` / `daily_answer` 처럼 **역할로** 짓고, 이름이 바뀌면 **ARB 문구만** 고치게 한다.

> 💡 **댓글을 어떻게 재사용할 것인가** — 지금 `post_comments`는 `post_id`에 묶여 있다.
> 두 갈래가 있다: ⓐ 답변마다 대응하는 행을 두고 `post_id`를 일반화한다,
> ⓑ `target_type` + `target_id`로 넓힌다. **ⓑ가 단순하지만 기존 FK를 잃는다** —
> 어느 쪽이든 `GardenService.addComment()`의 판정(깊이·길이·이미지 키)은 그대로 쓸 수 있게 뽑아낼 것.

### 2-3. 완료 기준

- [ ] **V14** 적용. 테이블·API 이름에 콘텐츠 이름(`moonlight`·`한마디`)이 없다

- [ ] 최신순/인기순 정렬이 동작하고 **인기순 = 좋아요+댓글 합**이다
- [ ] 작성 100자 제한(서버도 거절) · 이미지 1장

- [ ] `flutter analyze lib test` 0건 · `flutter test` 통과 · 서버 컴파일 성공

## 4. 작업하기 전에 꼭 읽을 것

**[12 §6](12-plan3-diff.md)의 원칙 둘**

1. **기획서에 없으면 사라진 것으로 본다.** 재활용은 "비슷해 보여서"가 아니라 **규칙이 실제로 같을 때만**.
   ④→⑤가 바로 그 조건을 만족해서 재활용하는 경우다.
2. 🚨 **콘텐츠 이름은 언제든 바뀐다** — **이름을 식별자로 쓰지 말 것.**

**단계마다 얻은 것**

- ② **숫자를 문구에 굳히지 말 것.** 한도는 서버가 `field`로 싣고 ARB가 조립한다.
  ④에서 `@Size(max=50)`을 걷어낸 것도 같은 이유다(애노테이션에는 상수만 들어간다).
- ③ 🚨 **제한은 화면이 아니라 서버가 건다.** 잠긴 데이터의 URL이 응답에 들어 있으면 제한이 아니다.
- ③ **삭제와 빈자리는 다르다.** 무언가를 걷어낼 때 *"이 자리에 다른 게 들어오나"* 를
  **기획서 이미지로** 확인할 것(스포트라이트 자리에 달빛 한마디가 들어왔다).
- ③ 겹쳐 놓는 **장식 레이어에는 `IgnorePointer`** — 없으면 아래 탭을 다 먹는다(함정 #38).

## 5. 개발 환경 시작

```bash
git pull origin main
```

[07](07-work-log.md) §2-2 루틴대로: MariaDB 기동 → 서버 `bootRun` → `adb reverse tcp:8080 tcp:8080` → `flutter run`.

| 잊으면 깨지는 것 | 왜 |
|---|---|
| 서버를 한 번 띄워 **V13까지 적용** | 댓글 3단계(V13)·가든 노출(V12)·메인 사진(V11) |
| `flutter pub get` → **`flutter gen-l10n`** | ARB 생성물이 저장소에 있다(함정 #28) |
| `assets/` 폴더가 늘면 **완전 재빌드** | 번들에 안 들어간다(함정 #30) |

- **실기기**: `--dart-define=API_BASE_URL=http://localhost:8080` 필수(함정 #29)
- **에뮬 2대**: `Pixel_10` + **`Pixel_B`** — 같은 AVD는 두 번 못 띄운다(함정 #32)
- **게이트 우회 옵션은 없다.** 대신 **18시 이전이면 `session_date`가 어제**다
- **가든을 확인할 땐** 무료 계정으로 — 앨범패스·프라임은 열람 제한이 안 걸린다
- **MariaDB를 내릴 땐** `mysqladmin -uroot shutdown` (앱 계정엔 SHUTDOWN 권한이 없다)
