## 3. ⑦단계에서 얻은 것 (다음 사람이 알아야 할 것)

### 🚨 값이 아니라 **"무엇을 세는가"** 를 먼저 볼 것

무료 번역이 기획서와 달랐는데, **숫자만 다른 게 아니었다.**

| 자리 | 기획서 | ⑦ 전 |
|---|---|---|
| 댓글창 | "댓글창 **5회 호출**" | 번역 **건수** 2 |
| 대화방 | "**5개까지**, 삭제 전까지" | 하루 **상대 수** 2 |

`2 → 5`만 고쳤다면 여전히 틀렸다. 댓글은 **창**이 단위라 창 하나에 댓글이 열 개여도
자리는 하나다. 대화방은 날짜가 아니라 **동시에 열어 둔 방의 수**다.

### 🚨 못 주는 것은 **받지도 말 것**

번역 공급자가 없으면 자리를 쓰지 않는다. 기능이 준비되지 않았을 때
**아무것도 소모하지 않는 것**이 옳은 기본값이다.

### 기획서가 허락한 삭제는 삭제해도 된다

GIF는 *"문제 있을 경우 **해당 기능 삭제**"* 라고 적혀 있었다. 키 없이 죽은 버튼을
남기는 것보다 낫다.

### 🐛 COALESCE는 **바깥**에

`SELECT COALESCE(likes, 0) FROM post_stats WHERE ...` — 컬럼 NULL만 막고
**행이 없으면** 0행 → null → int로 받다가 터진다. `SELECT COALESCE((SELECT ...), 0)`.
통계 행은 첫 노출 때 생기므로 **공유 직후에는 늘 없는 상태**다.

## 5. 작업하기 전에 꼭 읽을 것

**[12 §6](12-plan3-diff.md)의 원칙 둘**

1. **기획서에 없으면 사라진 것으로 본다.** 재활용은 **규칙이 실제로 같을 때만**.
2. 🚨 **콘텐츠 이름은 언제든 바뀐다** — **이름을 식별자로 쓰지 말 것.**

**단계마다 얻은 것**

- ② **숫자를 문구에 굳히지 말 것.** 한도는 서버가 `field`로 싣고 ARB가 조립한다.
- ③ 🚨 **제한은 화면이 아니라 서버가 건다.**
- ③ **삭제와 빈자리는 다르다.**
- ③ 겹쳐 놓는 **장식 레이어에는 `IgnorePointer`**(함정 #38).
- 📌 **사진을 누르는 자리는 `TappableImage`**(`shared/widgets/image_viewer.dart`).
- ⑤ **여러 조건은 한 문장으로 줄여 볼 것.**
- ⑥ **화면 상태를 목록에서 들고 오지 말 것.** 목록은 낡는다.
- ⑥ **우리가 지어낸 문구를 상대의 말인 척 두지 말 것.**
- ⑥-B 🚨 **화면이 숫자를 말해야 하면 서버가 그 숫자를 줘야 한다.**
- ⑥-B 🚨 **혜택 목록은 권리에서 나와야 한다** — 코드가 따로 봐주는 혜택은 화면에 안 뜬다.
- ⑦ 🚨 **값이 아니라 "무엇을 세는가"를 먼저 볼 것**(§3).
- ⑦ 🚨 **못 주는 것은 받지도 말 것**(§3).

## 6. 개발 환경 시작

```bash
git pull origin main
```

[07](07-work-log.md) §2-2 루틴대로: MariaDB 기동 → 서버 `bootRun` → `adb reverse tcp:8080 tcp:8080` → `flutter run`.

| 잊으면 깨지는 것 | 왜 |
|---|---|
| 서버를 한 번 띄워 **V22까지 적용** | 번역 쿼터 개편(V20)·평생 사용량(V21)·신청 우선권(V22) |
| `flutter pub get` → **`flutter gen-l10n`** | ARB 생성물이 저장소에 있다(함정 #28) |
| `assets/` 폴더가 늘면 **완전 재빌드** | 번들에 안 들어간다(함정 #30) |

- **실기기**: `--dart-define=API_BASE_URL=http://localhost:8080` 필수(함정 #29)
- **에뮬 2대**: `Pixel_10` + **`Pixel_B`**(함정 #32)
- **18시가 지나면 가든이 빈다** — 오늘 공유한 사람이 아직 없어서다(버그가 아니다).
  `scratchpad/verify_garden.py`의 `publish_with()`로 테스트 계정을 만들면 된다
- **번역 흐름을 보려면** `./gradlew bootRun --args='--app.translate.provider=mock'`
  (⚠️ 운영 금지 — 번역하지 않고 `〔ja〕` 표시만 붙인다)
- **가든/포스트 정보를 확인할 땐** 무료 계정으로 — 앨범패스·프라임은 열람 제한이 안 걸린다
- **`last_seen_at`은 소켓이 붙어야** 채워진다. REST만 두드리면 null인 게 정상이다
- **MariaDB를 내릴 땐** `mysqladmin -uroot shutdown`
