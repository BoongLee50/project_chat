## 4. 작업하기 전에 꼭 읽을 것

**[12 §6](12-plan3-diff.md)의 원칙 둘**

1. **기획서에 없으면 사라진 것으로 본다.** 재활용은 **규칙이 실제로 같을 때만**.
2. 🚨 **콘텐츠 이름은 언제든 바뀐다** — **이름을 식별자로 쓰지 말 것.**

🚨 **기능이 맞다고 화면이 맞는 게 아니다.** ②단계에서 포스트 기능만 보고 시안을 대조하지 않아
화면이 한참 어긋난 채로 남아 있었다(2026-08-30에 사용자가 짚어 줘서 고침).
**각 단계 완료 기준에 "기획서 이미지와 대조" 를 넣어 둘 것.**

**단계마다 얻은 것**

- ② **숫자를 문구에 굳히지 말 것.** 한도는 서버가 `field`로 싣고 ARB가 조립한다.
  ④에서 `@Size(max=50)`을 걷어낸 것도 같은 이유다(애노테이션에는 상수만 들어간다).
- ③ 🚨 **제한은 화면이 아니라 서버가 건다.** 잠긴 데이터의 URL이 응답에 들어 있으면 제한이 아니다.
- ③ **삭제와 빈자리는 다르다.** 걷어낼 때 *"이 자리에 다른 게 들어오나"* 를 **기획서 이미지로** 확인할 것.
- ③ 겹쳐 놓는 **장식 레이어에는 `IgnorePointer`** — 없으면 아래 탭을 다 먹는다(함정 #38).
- 📌 **사진을 누르는 자리는 `TappableImage`를 쓸 것**(`shared/widgets/image_viewer.dart`).
  `GestureDetector` 기본값으로는 `Image` 위의 탭이 안 들어와서 **세 번 반복된 실수**다.
- ⑤ **표를 넓힐 때는 회귀를 검증 항목에 넣을 것.** 댓글을 공용으로 바꾼 뒤
  *"포스트 댓글이 그대로 동작하는가"* 가 유일한 위험이었고, 그것만 확인하면 안전했다.
- ⑤ **여러 조건은 한 문장으로 줄여 볼 것.** 답글 자격이 "자기 것 금지 + 제3자 금지 + 3단계 제한"
  셋처럼 보였지만, **"부모를 쓴 사람의 상대만 단다"** 한 줄이 앞의 둘을 동시에 막는다.
  조건을 나눠 두면 나중에 하나가 빠져도 티가 안 난다.

[07](07-work-log.md) §2-2 루틴대로: MariaDB 기동 → 서버 `bootRun` → `adb reverse tcp:8080 tcp:8080` → `flutter run`.

| 잊으면 깨지는 것 | 왜 |
|---|---|
| 서버를 한 번 띄워 **V14까지 적용** | 달빛 한마디(V14)·댓글 공용화(V14)·가든 노출(V12) |

| `assets/` 폴더가 늘면 **완전 재빌드** | 번들에 안 들어간다(함정 #30) |

- **실기기**: `--dart-define=API_BASE_URL=http://localhost:8080` 필수(함정 #29)
- **에뮬 2대**: `Pixel_10` + **`Pixel_B`** — 같은 AVD는 두 번 못 띄운다(함정 #32)
- **게이트 우회 옵션은 없다.** 대신 **18시 이전이면 `session_date`가 어제**다
- **가든을 확인할 땐** 무료 계정으로 — 앨범패스·프라임은 열람 제한이 안 걸린다
