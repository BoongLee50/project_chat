## 4. 작업 시작 전 체크

```bash
git pull origin main
```

**이번 pull에서 반드시 해야 하는 것**(안 하면 깨진다)

| 해야 할 것 | 안 하면 |
|---|---|
| 서버를 한 번 띄워 **V8 적용** | 달빛가든 피드가 `content_updated_at` 없다고 실패 |
| `flutter pub get` → **`flutter gen-l10n`** | ARB 새 키 8개가 없어 `undefined_getter`(함정 #28) |
| `flutter pub get` 후 **완전 재빌드** | `assets/images/garden/`이 번들에 안 들어가 "Unable to load asset"(함정 #30) |

그다음 [07](07-work-log.md) §2-2 "매번 — 개발 시작 루틴"대로:
MariaDB 기동 → 서버 `bootRun` → `adb reverse tcp:8080 tcp:8080` → `flutter run`.

**실기기(폰)에서 볼 거면** `--dart-define`을 빼먹지 말 것 — 빼면 에뮬레이터 주소가 박혀
**로그인 화면에서 아무 반응 없이** 멈춘다(오류 로그도 안 남는다, 함정 #29):

```bash
flutter build apk --debug --dart-define=API_BASE_URL=http://localhost:8080
```

**낮에 작업한다면** 게이트가 닫혀 있어 대부분의 기능이 막힌다. §2-4의 우회 방법을 쓸 것
(`--args='--app.gate.open-hour=0'`). 이번 작업은 **화면 문구 전반**이 대상이라 게이트를 열어 두는 편이 낫다.

**에뮬 언어 전환**은 `adb shell setprop`이 막혀 있다(프로덕션 이미지). 앱별 언어 설정으로 바꿀 것 — 함정 #26.
