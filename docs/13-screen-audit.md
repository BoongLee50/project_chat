## 1. 대화방 (6-1) — ❌ 차이 큼

시안은 **탭 두 개 + 두 가지 목록**인데, 지금은 **한 목록에 다 섞여** 있다.

| 요소 | 기획서 | 지금 |
|---|---|---|
| 배경 | 밤 풍경 **배경 이미지** + 타이틀 | 배경 없음(검정) |
| 상단 | `대화방` + **[VIP]** + `[★ 80]` | 타이틀·부제만 |
| 탭 | `[💬 대화 N]` `[✉ 받은 신청 N]` **두 탭** | 없음(합쳐진 한 목록) |
| 대화 목록 행 | 아바타+**N 미확인 배지** · 이름 나이 국기 · 시간 · **🟢온라인** · 메시지 **2줄**(원문+번역) · 우측 **친구 관계 버튼** | 아바타 · 이름 국기 · `친구` 뱃지 · 시간 · 메시지 1줄 |
| **친구 관계 버튼** | `친구` / `친구 신청` / `신청 대기` **3상태** | 상태 뱃지만(누를 수 없음) |
| 받은 신청 | **2열 그리드 카드**(사진·온라인·N·이름/나이/국기·시간·`>`) | 목록 안 한 줄 |
| 수락/거절 | 카드를 눌러 **[포스트 정보]** 화면에서 | 목록에서 바로 |

**필요한 것**: [포스트 정보] 공통 화면(§2), 탭 분리, 친구 상태 버튼, 미확인 배지, 온라인 표시.

## 2. [포스트 정보] 공통 화면 (img15·16 우측) — ❌ **없다**

**여러 곳에서 부르는 상대 정보 풀스크린.** 지금 이 화면 자체가 없다.

- 사진 풀스크린 + 우상단 `1/9` + 좌상단 뒤로 + 우상단 **⋮ 메뉴**
- ⋮ 메뉴: `프로필 보기` / `신고하기` / `차단하기` (+ 친구면 `친구해제`)
- 하단: 이름 나이 국기 → **대화 신청 메시지**(따옴표) → `관심사` 카드 → `소개 한마디` 카드
- **부르는 곳에 따라 하단 버튼이 다르다**
  - 대화방 받은 신청 → `[✕ 거절]` `[✓ 수락]`
  - 친구 목록 → `[💬 대화하기]`
  - 달빛가든 → 대화 신청

## 7. 고치는 순서

큰 것부터, 그리고 **의존이 있는 것부터**.

1. **[포스트 정보] 공통 화면** — 대화방·친구·가든이 전부 이걸 부른다(⑥단계의 핵심)
2. **대화방** — 탭 분리 + 받은 신청 그리드 + 친구 상태 버튼
3. **친구 목록** — 3열 그리드 + 탭 + 도시
4. **프로필** — 활동 지역 카드 + Prime 배너 + 접속 표시
5. **채팅창** — 상단 바·⋯ 메뉴 (이모지·GIF는 ⑦)
6. 남은 대조(로그인·온보딩·대화 신청·BM)

> 📌 **1~2는 ⑥단계와 같은 일이다.** 화면 감사가 ⑥단계의 범위를 넓혀 준 셈이라
> 따로 단계를 만들지 않고 ⑥에서 함께 처리한다.
