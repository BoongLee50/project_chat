## 2. [포스트 정보] 공통 화면 (img15·16·17 우측) — ✅ 새로 만듦

**한 응답으로 세 곳이 같은 화면을 연다** — `GET /users/{id}/post-info`.

- 사진 풀스크린 + 우상단 `1/9` + 좌상단 뒤로 + 우상단 ⋮ 메뉴
- ⋮: `프로필 보기` / `신고하기` / `차단하기` (+ 친구면 `친구 해제`)
- 하단: 이름 나이 국기 → **신청 메시지**(따옴표) → `관심사` → `소개 한마디`

> 🚨 **하단 버튼은 부르는 쪽이 아니라 데이터가 정한다.**
> 부르는 쪽이 지정하면 목록이 낡았을 때 **이미 수락한 신청에 [수락]이 다시 뜬다.**
> 화면에 들어올 때 서버에 물으므로 여기가 항상 최신이다.
>
> 1. 답하지 않은 **대화 신청** → `[✕ 거절] [✓ 수락]`
> 2. 답하지 않은 **친구 신청** → 같은 두 버튼(친구 쪽)
> 3. 살아 있는 대화방이 있다 → `[💬 대화하기]`
> 4. 그 외 → `[대화 신청]`

**열람 제한도 여기서 걸린다** — `GardenService.canViewAllPhotos()`를 **그대로** 부른다.
가든에서 막아 놓고 이 화면에서 뚫리면 막지 않은 것과 같다(함정 #18).

| 요소 | 기획서 | 지금 |
|---|---|---|
| 배경 | 밤 풍경 배경 이미지 | 🟡 그러데이션(리소스 대기) |
| 상단 | `친구` + `[Prime]` `[★ 80]` · `지금 접속 중 36명` | ✅ |
| 탭 | `[친구 목록 N]` `[✉ 받은 신청 N]` | ✅ |
| 필터 | **없음** | ✅ 성별·나이·국가 칩 **걷어냄**(서버 질의는 그대로 받는다) |
| 목록 | **3열 그리드** — 원형 사진(국기 배지) · 이름 나이 · **도시** · 접속 상태 | ✅ |
| 카드 탭 | **[포스트 정보]** 호출 | ✅ (`FriendPostSheet` 삭제) |
| 받은 신청 | 목록 + **신청 한마디** + `>` | ✅ (친구 신청 메시지 25자, V17) |

> 🟡 **도시 이름의 표기**: 시안은 `seoul` `tokyo` 처럼 **소문자 영문**이다.
> 지금은 각 언어의 도시명(`ProfileCatalog.cityLabel`)을 쓴다 — 영문 로마자 표를 새로
> 만들 근거가 없어서다. 기획이 로마자를 원하면 표 하나만 더하면 된다.

> 🟡 **접속 상태 색이 세 가지**인 건 장식이 아니다. 지금 있는 사람(초록) /
> 방금까지 있던 사람(금색, 12시간 이내) / 오래 안 온 사람(회색)을 한눈에 가른다.
> 마지막 접속은 프레즌스(60초 TTL)로 알 수 없어 **`users.last_seen_at`(V16)** 을 새로 두었다.
