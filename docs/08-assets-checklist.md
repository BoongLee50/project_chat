# 달빛톡 — 리소스(이미지·아이콘) 체크리스트

> **이 문서의 용도**: 디자이너/기획자에게 그대로 전달할 수 있는 **필요 리소스 목록과 규격**.
> 현재 앱에 들어 있는 이미지는 기획서에 딸려온 **임시 더미 4장**뿐이고, 나머지는 전부 미제작 상태다.
> 파일이 준비되면 이 문서의 체크박스를 채우고 [04 로드맵](04-progress-and-roadmap.md)에도 반영할 것.

### 📌 전달 예정 (2026-08-03 기획 측 회신)
**기획에서 화면 이미지를 자르는 중이고, 정리되는 대로 먼저 전달해 준다.**
→ 그때까지 이 문서의 이미지 항목은 **대기**. 임시본으로 뭔가를 다듬을 필요 없다.
받으면 체크박스를 채우고 [04 로드맵](04-progress-and-roadmap.md)에도 반영할 것.

받을 때 **함께 확인할 것 2가지** (미팅 안건 형태는 [10](10-open-questions.md) §2)
1. **원본 출처·라이선스** — 아래 라이선스 항목 참고. 받는 김에 같이 물어 두면 두 번 안 묻는다.
2. **글자가 박혀 있지 않은 버전인지** — 지금 로그인 배경에는 한국어 문구가 그림으로 구워져 있어
   일본어로 앱을 켜도 그 부분만 한국어로 남는다(§1 공통 주의 참고).

### ⚠️ 라이선스 먼저 확인할 것
남아 있는 4장은 **기획서에 딸려온 이미지**라 출처가 불명확하다. 스톡 사진이면 상업적 사용 범위가,
AI 생성이면 또 다른 조건이 걸릴 수 있다. **개발 중에는 문제없지만 스토어 출시 전에는
출처 확인 또는 교체가 필수**다. 기획자에게 원본 출처를 미리 확인해 둘 것.
→ 교체본이 오기로 했으므로 이 리스크는 해소될 전망이지만, **새로 받는 것도 출처를 확인해야 한다.**

## 1. 앱 내 이미지

| # | 리소스 | 용도 | 권장 규격 | 상태 |
|---|--------|------|-----------|------|
| 1 | 로그인 배경 | 로그인 화면 전체 배경 | **1080×2640**, JPG, 다크톤, **글자 없이** | ⏳ 임시본 있음(한국어 문구가 구워져 있음) |
| 2 | 온보딩 배경 ×3 | 닉네임·출생년도·성별/국가 단계 | **1080×2640**, JPG | ⏳ 임시본 있음 |
| 3 | 기본 프로필 이미지 | 사진 미등록 사용자 | 512×512, PNG(투명) | ❌ |
| 4 | 빈 상태 일러스트 ×4 | 친구 없음 · 대화 없음 · 포스트 없음 · 피드 없음 | 512×512, PNG(투명) | ❌ |
| 5 | 달(月) 심볼 | 로고·빈 상태·로딩에 반복 사용 | SVG 또는 512 PNG | ❌ |

**공통 주의**
- 앱은 **다크 테마 고정**이다. 밝은 배경 이미지는 화면과 충돌한다.
- 배경 이미지 위에 텍스트가 올라가므로 **중앙~하단부는 어둡고 단순하게**.
- 세로 전용(폰). 태블릿·가로는 현재 대상 아님.
- ⚠️ **원본 1080×2640(22:9)은 대부분의 폰보다 길다 — 위아래가 잘린다.**
  화면을 꽉 채우는 방식(`BoxFit.cover`)이라 가로를 맞추고 남는 세로를 **가운데 기준으로 잘라낸다.**
  20:9 폰(1080×2400)에서 위아래 각 **약 120px**, 19.5:9(1080×2340)에서 각 **약 150px**.
  → **위아래 6%(각 160px) 안에는 중요한 것을 두지 말 것.** 달·로고 같은 주요 요소는 중앙쪽으로.
- ⚠️ **이미지 안에 글자를 넣지 말 것.** 지금 로그인 배경(#1)에 로고와 함께
  "밤에만 만나는 대화 / 오늘, 당신의 밤을 특별한 사람과 함께해요"가 **그림으로 구워져 있다.**
  일본어로 앱을 켜도 이 두 줄만 한국어로 남는다(2026-08-02 에뮬레이터에서 확인).
  → 최종본은 **글자 없는 배경**으로 받고, 문구는 화면 텍스트(ARB)로 얹는다.
  로고(달빛톡 워드마크)는 브랜드 자산이라 그대로 두어도 되지만, 일본어 워드마크가 필요한지는 별도 판단.

## 5. 결정이 필요한 것

| 항목 | 선택지 |
|---|---|
| 기능 아이콘 | Material 기본 유지 vs 커스텀 아이콘셋 제작(하단 5탭 + 화면 내 아이콘 약 30종) |
| 국기 표시 | 이모지 유지(무료·간단, 기기마다 모양 다름) vs 이미지(일관됨, KR/JP 2장이면 충분) |
| 폰트 | 시스템 기본 vs 커스텀(한·일 동시 지원 필요 — Noto Sans KR/JP 등) |
| 이미지 포맷 | JPG/PNG vs WebP(용량 30~50% 절감, 안드·iOS 모두 지원) |

## 6. 넣는 방법 (참고)

```
assets/images/        # 앱 내 이미지 — pubspec.yaml에 폴더째 등록돼 있어 파일만 넣으면 된다
```
- `pubspec.yaml`의 `assets: - assets/images/` 는 이미 설정됨. **개별 파일 등록 불필요.**
- 앱 아이콘·스플래시는 패키지 도입 후 `flutter pub run` 한 번으로 생성.
- 사용자가 올리는 사진(프로필·포스트)은 여기가 아니라 **서버 스토리지**로 간다(02 문서 §3).
