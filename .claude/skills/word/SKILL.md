## 기획서 9장 요지 (261011 본문 + 2026-10-11 사용자 결정 — 바뀌었으면 본문·결정을 따른다)

- **KST 18시에 모든 정보 초기화 + 새 질문**. 타이틀은 **남은 시간만, 분까지**(`05 : 48`). 참여 인원은 빠졌다
- [참여하기] → **[내 한마디 등록] 시트가 아래에서 올라온다**. **등록해야 [답글 목록]이 열린다**(서버도 403으로 막는다)
- 🚪 **오늘 이미 답했으면 다음 질문(18시)까지 타이틀을 띄우지 않고 바로 목록**(사용자 결정) — `DailyIntroScreen`이 목록을 대신 그린다. 들어올 때마다 새로 읽는다(함정 #93)
- 등록 시트 `✕` → **애니메이션 없이 뚝 사라지고 글·사진 초기화**(사용자 결정)
- 답변글 **200자, 띄어쓰기 포함, 코드포인트로 센다**(시안 `0 / 300`은 오류 — 기획자 확인). 사진 **선택·1장**, **촬영 / 앨범** 중 고른다(공용 `PhotoSourceSheet` — 포스트·프로필과 같은 시트)
- [답글 목록]: 아래에서 올라오는 시트 형태 · [최신](기본)/[인기](= 좋아요 + 댓글 합) · [내 한마디] · 얼굴 → [프로필 보기] · [나가기] → 메인
- 🌐 목록 셀: **나라가 다르면 자동 번역 + 셀 오른쪽 위 [원문보기]**, **같은 나라면 버튼이 안 보이고 안 눌린다**(대화방·친구·프로필의 "흐리게"와 다르다). 🚧 번역 기능은 아직 없다
- 내 한마디가 없는데 [내 한마디]: *"아직 작성한 내 한마디가 없어요. 오늘의 질문에 답해 보세요."*
- [답글 상세]: 좋아요 +1 · 댓글 **A → B → A까지**(A=댓글 단 사람, B=글쓴이 — 지금 3단계 규칙과 같다) · 댓글 **50자**·사진 1장 · 첨부 사진은 원본만 팝업
- 번역: **[답글 상세] 창 5회 호출까지 무료** → 다 쓰면 *"무료 번역을 모두 사용했어요…"*. Prime·자동번역 패스는 무제한

## 🚧 B 묶음 — [답글 상세] (그림·기획이 더 와야 한다, 2026-10-11 사용자 전달)

- 유저 이름 **바로 아래부터 스크롤**
- 시안의 "시스템 이모티콘 호출" 단추는 이모티콘이 아니라 **사진 첨부**다
- 댓글 입력에서 **시스템 이모지**를 낼 수 있게 · 댓글에 **보내기 버튼**
- 지금 상세는 옛 어두운 화면 그대로다 — 그림이 오면 통째로 다시 그린다

## 알아둘 것

- 셀 `● ON` = 접속 중, 아니면 `N분 전`(쓴 지 얼마) — **사용자 확인으로 확정**(2026-10-11)
- 셀 사진을 누르면 **원본만 가운데 팝업**(배경을 누르면 닫힘, 공용 `showOriginalImage`). 사진 밖은 상세로
- 타이틀 질문 글 기울기 **-11°**(배경 실측 -10°보다 조금 더 — 사용자 지시, -12°에서 되돌림)
- 기획 확인 대기: 무료 번역 5회의 **초기화 주기** — 지금은 영업일마다 초기화로 읽었다. 평생 5회면 `lifetime_usage`로(09 §2-1)
- 빈 목록 — 등록해야 들어오므로 **적어도 내 것이 있다**. 빈 상태 화면은 만들지 않았다(차단으로 다 걸러질 때만 문구 한 줄)

- 그림 함정: 셀 틀 9조각은 `scale` 없이(함정 #90) · 키보드 무시 화면의 안내는 키보드 위로(#91) · 눌린 [최신]/[인기]는 RGB라 알약으로 잘라 그린다
