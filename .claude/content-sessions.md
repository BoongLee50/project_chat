  (예전 전달본의 `Example/` 폴더도 시안이다)
- 🚨 **같은 그림은 한 벌만**(사용자 결정 2026-11-15) — 여러 화면 폴더에 **바이트까지 같은 그림**이 오면(이름이 달라도) 저장소에는
  **먼저 들어온 곳 한 벌만** 두고, 다른 화면은 그 경로를 가리킨다. 군더더기 21장을 이렇게 정리했다(07 §4 2026-11-15).
  - **모든 리소스를 다 뒤질 필요는 없다** — 자기 화면 폴더만 보고 대조 도구를 돌리면 된다. 새 그림이 이미 다른 곳에 있으면 도구가
    `⚠️ 같은 그림이 이미 있다: <경로>`로 알려 준다 → 들이지 말고 그 경로를 쓰고, 도구의 **`SHARED`** 표에 한 줄 더한다.
  - 공용 그림이 **한 폴더에서만 바뀌어 오면** 도구가 `🟠 공용 그림 다름`으로 따로 알린다 — 고치면 그 한 벌을 쓰는 화면이 **전부** 바뀐다.
    같이 바뀌어도 되면 그대로 갈아끼우고, 아니면 그때 따로 들여 가른다(`SHARED`에서 그 줄 지움). 판단이 애매하면 사용자에게 묻는다.
  - 공용 그림을 쓰는 상수에는 주석으로 출처를 적는다(예: `chat_art.dart` 국기 → 가든). 지금 공용 목록 = `SHARED` 표.

## 4. 🚨 동시 작업 규칙 — 아홉 세션(· 여러 기기 · 여러 계정)이 한 저장소를 쓴다

> 다른 기기·다른 Claude 계정으로 들어오는 경우의 추가 규칙은 **§6**. 이 절의 규칙은 누가 들어오든 똑같이 지킨다.

1. **내 콘텐츠 파일만 고친다.** 아래 **공용 파일**을 고쳐야 하면 최소한으로 하고, 끝에 보고할 때
   *"공용 파일 ○○를 고쳤다 — △△ 화면도 함께 바뀐다"* 를 꼭 적는다.

   | 공용 파일 | 누가 같이 쓰나 |
   |---|---|
   | `lib/shared/widgets/*`(`design_canvas.dart`·`art_top_bar.dart`·`main_bottom_nav.dart` 등), `lib/core/*` | 전부 |
   | `lib/features/chat/presentation/widgets/talk_cell.dart`·`request_popup.dart` | **대화방·친구**(셀 · 팝업 세 개가 한 벌) |
   | `lib/features/chat/` 의 `chat_provider` · `chat_api` · `chat_models` · 서버 `chat/` | **대화방·채팅창**(목록·신청 ↔ 메시지·소켓) |
   | `shared/widgets/art_top_bar.dart`([Prime] 문) · `shared/widgets/translate_pass_button.dart`([번역] 문) | 전부 ↔ **상점** |
   | `lib/features/chat/presentation/widgets/chat_request_dialog.dart` | 대화방·가든(4-3 대화 신청) |
   | `lib/features/garden/presentation/widgets/comments_sheet.dart` · 서버 `comment/` | **가든·달빛 한마디**(포스트 댓글과 한마디 댓글이 한 벌) |
   | `lib/features/postinfo/*`(`profile_view_screen.dart`·`post_info_provider.dart`) | 가든·대화방·친구·프로필 |
   | `lib/shared/widgets/request_message_input.dart`(신청 한마디 100자) | 대화방·친구 |
   | `pubspec.yaml` · `lib/l10n/*.arb`(+생성물) · `server/.../common/*` · `application.yml` | 전부 |

2. **커밋은 경로를 집어서 내 파일만.** `git add <파일들>` → `git commit`.
   🚫 `git add -A` · `git add .` · `git commit -a` · `git stash` · `git checkout -- .` · `git reset --hard` 금지 —
   같은 폴더의 **다른 세션이 쓰다 만 변경을 쓸어 담거나 지운다.**
   `git status`에 내가 만들지 않은 변경이 보이면 **손대지 않는다**(다른 세션 것이다).
3. **Flyway 번호는 경쟁이다.** 새 마이그레이션을 만들기 **직전에**
   `git pull --ff-only origin main` → `ls server/src/main/resources/db/migration | sort -V | tail -3`으로 최신 번호를 보고, 만들면 **바로 커밋하고 바로 푸시**한다
   (다른 기기·계정은 푸시된 것만 본다). 같은 번호가 둘이면 서버가 아예 안 뜨고 **모든 세션이 다 멈춘다.** 문서의 함정 번호(`docs/07` §3 `#NN`)도 같다.
4. **ARB 키는 그 화면의 기존 접두어를 따른다** — 포스트 `home*` · 가든 `garden*` · 대화방 `chat*` ·
   친구 `friend*` · 프로필 `profile*`/`interest*` · 달빛 한마디 `daily*` · 채팅창 `chat*`(대화방과 같은 접두어 — 목록은 `chatRooms*`) · 상점 `prime*`·`store*`·`boost*`·`pass*`·`luna*`. **ko·ja 둘 다** 넣고 `flutter gen-l10n` 생성물도 함께 커밋.
5. **서버(8080)와 폰은 하나다.** 서버를 다시 띄우면 다른 세션의 검증이 끊긴다 — 서버 코드나 마이그레이션을
   바꿨을 때만 재기동하고, 했다고 보고한다. `flutter analyze` 오류가 **남의 파일**에서 나면 고치지 말고 알린다
   (다른 세션이 쓰는 중일 수 있다).

6. **문서도 나눠 쓴다.**

사용자는 **이 PC에서 Claude 계정 둘을 번갈아** 쓴다(사용량이 차면 다른 계정으로 옮겨 이어서 한다). 확인된 사실(2026-11-15):

- 세션이 **백그라운드로 띄운 서버·빌드는 그 세션 소유**다. 2026-11-15 15:28에 8080 서버·DB·에뮬이 한꺼번에 꺼져 있었다(누가 껐는지 기록 없음).

**넘기는 쪽(계정을 바꾸기 전)** — 사용자가 "다른 계정으로 옮긴다"고 하면 이 순서로:
1. 다 된 것은 **내 파일만 경로로 커밋 → 푸시**(§4-2).
2. **다 못 한 것**은 둘 중 하나:
   - 커밋할 만큼 됐으면 `wip(<콘텐츠>): …` 로 커밋·푸시하고, 무엇이 남았는지 09 §0 내 줄에 적는다.

     ⚠️ 이게 없으면 받는 세션은 그 미커밋 변경을 **"남의 쓰다 만 변경"으로 보고 손대지 않는다**(§4-2) — 일이 거기서 멈춘다.
3. 07 §4 내 로그에 그날 한 것 · **확인 못 한 것**(실기기·에뮬·검증 스크립트)을 적는다.
4. 서버·DB·에뮬을 **켜 둔 채로 넘기는지, 껐는지** 한 줄 적는다(09 §0 내 줄 또는 07 로그). 내가 띄운 8081 둘째 서버는 끄고 넘긴다.

**받는 쪽(새 계정에서 세션을 열면)** — §2 시작 절차 그대로 + 이것만 더:
1. 09 §0 내 줄에 `🔄 이어받기`가 있으면 거기 적힌 **미커밋 파일은 내 것으로 이어받는다** — `git status`·`git diff <그 파일>`로 내용을 먼저 본다.
   이어받아 커밋하면 `🔄` 줄은 지운다(다 했으면 결과로 바꿔 적는다).
2. `🔄` 줄에 없는 미커밋 변경은 여전히 **남의 것**이다(§4-2) — 다른 콘텐츠 세션이 지금 쓰는 중일 수 있다.
3. 서버가 꺼져 있으면(`curl -s -o /dev/null -w "%{http_code}" -X POST http://localhost:8080/auth/social`이 `000`) DB → 8080 → 에뮬 순으로 띄운다(07 §2-2).

4. 더 앞의 맥락이 꼭 필요하면 같은 PC의 지난 대화 기록 `~/.claude/projects/D--project-chat/*.jsonl`을 **검색만** 한다(파일이 크다 — 수십~백 MB. 통째로 읽지 말 것).

**같은 콘텐츠를 두 계정이 동시에 열지 않는다**(위 2번) — 계정을 바꾸면 **앞 계정의 그 세션은 닫거나 멈춘 상태**여야 한다.
두 계정을 동시에 돌릴 때는 **서로 다른 콘텐츠**만 맡긴다(예: A 계정 `/garden`·`/post`, B 계정 `/shop`·`/word`). 공용 파일(§4-1 표)은 두 계정이 같이 걸리니 고친 쪽이 보고에 적는다.
